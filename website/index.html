What it is

An agent, not a chat window.

Pulse can read your project, make a plan, edit real files, run the tests and prove the result. Chat is for thinking; Code is for doing.

Reads the whole context

STAR.md, AGENTS.md, PULSE.md, project settings, git history, skills and knowledge all reach the model before it acts.

Edits real files

Targeted edits, multi-file changes, a real diff review and a safe revert. Every change is yours to inspect.

Proves the work

Runs your own test command, starts the server, checks the output and reports exactly what it verified.

Brings your tools

Outlook, Slack, Notion, Linear, GitHub, Canvas and more connect through local MCP servers with your own tokens.

Works in parallel

Git worktrees keep separate sessions on separate branches; research subagents explore in parallel without touching the work.

Permission first

Ask, accept edits, plan or bypass. Plan mode is read-only on the server, and every write or command is visible.

The harness

Your model. Your data. No lock-in.

Pulse is the harness around the model, not another hosted chatbot. DeepSeek, OpenAI, Anthropic, Google, OpenRouter, Ollama, LM Studio or any OpenAI-compatible endpoint — switch whenever you want.

  • Keys live in ~/.star-code/auth.json, never in a Pulse server.
  • Sessions, skills, connectors and diffs stay on disk.
  • Only the provider you choose sees your prompts.
  • The same agent runs as desktop app, pulse web, and the Star Code CLI.

How it works

From a sentence to a verified change.

No hidden pipeline. The agent shows the plan, the tool calls and the result.

01

Point it at a folder

Open a project or name one in chat. Pulse reads the instructions and the parts of the repo the task touches.

02

Say what you want

It asks when a decision is genuinely yours, then plans and works. Use Chat for questions, Code for changes.

03

Review what changed

Inspect the diff, run the tests, revert a change. The turn ends with files, commands and what was verified.
