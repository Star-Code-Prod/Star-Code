# Markdown
- One H1; headings in order.
- Use a real language tag on code fences.
- Tables need a header separator row.
- Blockquotes for caveats; callouts use `> [!TIP]` etc.
- Link text should describe the target.
- Preview the rendered result before shipping docs.
