# Spreadsheets
- Use the office/xlsx workflow for .xlsx, not CSV for a workbook.
- Put inputs, calculations and presentation on separate sheets when useful.
- Use real formulas; do not paste hardcoded results.
- Format numbers, headers, widths and freeze panes.
- Recalculate and verify computed values before delivery.
- Keep a note of assumptions.
