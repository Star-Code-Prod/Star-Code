# Documents
- Use the office/docx workflow for .docx.
- Apply heading styles instead of manual bold/size.
- Keep margins, body font and spacing consistent.
- Use real tables for tabular content.
- Add page numbers and a title where appropriate.
- Open/validate the result before delivering.
