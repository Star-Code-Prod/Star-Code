# Git
- Start with `git status` and `git diff`; know what is staged and untracked.
- Commit one logical change with a specific message.
- Never commit secrets, build output, temp files or unrelated edits.
- Do not force-push, reset --hard or rewrite shared history without explicit permission.
- Before a release, check the changelog version matches the package version.
- Report the commit hash and branch.
