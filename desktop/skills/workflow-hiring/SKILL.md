# Hiring

## Scorecard
- Define outcomes for the first 6-12 months and 4-6 competencies.
- Separate must-haves from learnable traits. Remove requirements that are not job-related.

## Loop
- Map each competency to one interview or work sample.
- Write behavioural questions with follow-ups; define what strong, mixed and weak answers look like.
- Use the same rubric for every candidate.

## Work sample
- Keep it representative, time-boxed and paid when substantial.
- Evaluate the artifact against the rubric, not against another candidate.

## Debrief
- Gather independent written assessments before discussion.
- Decide on evidence; record reasons. Give candidates a clear, timely outcome.
- Never make a decision from a single unstructured impression.
