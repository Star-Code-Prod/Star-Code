# Accessibility
- Every interactive element is reachable and operable by keyboard.
- Visible focus; no focus trap except an intentional modal.
- Inputs have labels; images have useful alt text (or empty alt if decorative).
- Do not convey meaning by color alone.
- Check contrast against the actual background.
- Test with the keyboard and the accessibility tree.
