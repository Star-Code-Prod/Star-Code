# Copywriting

## Brief
- Name the audience, their situation, the promised outcome and the proof.
- Choose one primary action per surface.

## Draft
- Lead with the user's problem or desired outcome, not the company history.
- Use concrete nouns and verbs. Cut adjectives that do not add information.
- Structure: hook -> value -> proof -> objection -> CTA.
- Write the headline last; make it specific enough to be believable.

## Edit
- Read it aloud; remove jargon, filler and repeated ideas.
- Check every claim; remove or qualify what cannot be supported.
- Provide 2-3 headline alternatives and one shorter version.

## Fit
- Match the surface and length: hero, email, button, empty state.
- Keep UI copy consistent with the app's vocabulary. Deliver inline unless the user asks for a file.
