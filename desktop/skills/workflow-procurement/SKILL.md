# Procurement

## Requirements
- Separate must-have, weighted nice-to-have and disqualifiers.
- Define users, volume, integrations, data sensitivity and budget range.

## Compare
- Build a matrix scored on the same criteria; record the evidence source.
- Calculate total cost over the contract term, including seats, usage, implementation and exit.
- Check security: data location, subprocessors, SSO/SCIM, audit logs, retention, export.

## Validate
- Run a time-boxed trial on the real workflow, not a demo script.
- Ask for two references with a similar size and use case.
- Test export and cancellation before committing.

## Recommend
- Name the winner, the tradeoffs and the conditions that would reverse the decision.
- Do not accept a vendor's claimed compliance as proven; ask for the report.
