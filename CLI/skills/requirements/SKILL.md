name: requirements
description: Turn a vague feature idea into explicit acceptance criteria, scope, non-goals and a verification plan before coding.
---

# Requirements
- Write the user-visible outcome, not the implementation.
- List 3-5 acceptance checks that can be observed or run.
- State non-goals and what is deliberately out of scope.
- Name the files or surfaces likely to change.
- If a decision is genuinely the user's (copy, platform, tradeoff), ask one question; otherwise choose and say why.
- Get a yes on the plan before a large change.
