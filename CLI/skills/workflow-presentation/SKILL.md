# Presentation

## Frame
- Define the audience, the decision they need to make and the one sentence they should remember.
- Choose the format: pitch, update, teaching, proposal or keynote.

## Story
- Use a clear arc: context -> tension -> insight -> recommendation -> next step.
- One idea per slide. Put the takeaway in the title, not a generic label.
- Start with the hook; end with the ask.

## Build
- 8-14 slides for a talk; fewer for a decision. Use large type, real content and one visual per key point.
- Tables only when the comparison matters. Keep sources on the slide or in notes.
- Write speaker notes for what the slide does not say.

## Check
- Read only the slide titles: does the argument stand?
- Remove any slide that does not change the decision.
- Ask before publishing an artifact or file; otherwise deliver the outline and slide copy in chat.
