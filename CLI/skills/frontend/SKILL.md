# Frontend
- Read the existing components, tokens and conventions first.
- Build the real states: loading, empty, error, disabled, focus.
- Keep layout responsive at narrow and wide widths.
- Use semantic elements and keyboard paths.
- Reuse tokens; do not invent hardcoded colors.
- Verify in the running app, not only in code.
