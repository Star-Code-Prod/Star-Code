# Competitive analysis

## Frame
- Define the decision, the segment and the comparison set.
- Separate direct competitors, adjacent alternatives and "do nothing".

## Gather evidence
- Use current sources; record URL, date and what is actually claimed.
- Compare on the same dimensions: audience, core job, onboarding, pricing, differentiators, weaknesses, proof.
- Do not compare a marketing claim with a shipped feature without labelling it.

## Analyze
- Build a matrix with a small number of meaningful dimensions, not a feature-count contest.
- Identify where the market is crowded, where it is underserved and what is table stakes.
- State assumptions and gaps in the evidence.

## Recommend
- Give the implication for positioning, roadmap or messaging.
- Include what would falsify the recommendation.
