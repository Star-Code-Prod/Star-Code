# Technical writing
- Name the reader and what they need to do.
- Lead with the outcome; details after.
- Short sentences, concrete verbs, one idea per paragraph.
- Use a real example that runs.
- Define jargon once; link instead of repeating.
- Cut anything that does not help the reader act.
