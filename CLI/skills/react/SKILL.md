# React
- Derive state instead of duplicating it.
- Keep effects for external sync only; clean up subscriptions.
- Use stable keys, not array indexes for reorderable lists.
- Handle loading, empty and error states.
- Avoid unnecessary memoization; measure first.
- Test the interaction, not implementation details.
