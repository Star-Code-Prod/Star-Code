# Presentations
- One idea per slide; 3-5 lines of text.
- Open with the hook, close with the takeaway.
- Use a consistent title position and type scale.
- Prefer one strong visual over decoration.
- Keep speaker notes for detail.
- Validate the .pptx renders before delivery.
