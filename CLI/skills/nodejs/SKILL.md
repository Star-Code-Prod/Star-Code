# Node.js
- Await or return every promise; no floating async work.
- Handle errors at the boundary; do not swallow them.
- Stream large files instead of buffering.
- Close servers, sockets and timers on shutdown.
- Use ESM consistently with the package setting.
- Check the Node version the project supports.
