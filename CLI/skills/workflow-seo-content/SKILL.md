# SEO content

## Intent
- Identify the searcher, the intent (learn, compare, buy, fix) and the page type that satisfies it.
- Collect the real query variants and the questions the page must answer.

## Outline
- Answer the core question in the first screen.
- Use sections that map to sub-intents; include comparison tables, steps or examples where useful.
- Plan internal links and one clear next action.

## Write
- Specific, first-hand, non-repetitive content. No keyword stuffing.
- Cite sources for claims and dates. Use the user's vocabulary.
- Metadata: title under ~60 chars, description that earns the click, canonical and social image.

## Check
- Does the page satisfy the intent without scrolling? Is every heading useful?
- Avoid thin AI filler, fake statistics and invented citations.
