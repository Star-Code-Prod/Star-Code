# Performance
1. Define the slow operation and a number that represents it.
2. Measure: profile, trace, query plan or timing.
3. Find the dominant cost, not every small cost.
4. Change one thing; re-measure with the same method.
5. Check memory, startup and worst-case input.
6. Report before/after and what remains.
