# Data analysis
1. Load and inspect: shape, dtypes, head, missing values.
2. Clean types and dates before analysis.
3. Check totals and duplicates; state exclusions.
4. Compute the metric with a reproducible script.
5. Visualize only when it adds signal.
6. Report the method and the caveat, not just the number.
