# Data story

## Start with the decision
- State the question and the action the audience is considering.
- Pick the one headline number or comparison that changes the decision.

## Evidence
- Show the smallest chart or table that proves the headline; label axes, units and time window.
- State the denominator, the comparison and the uncertainty.
- Separate correlation from causation.

## Caveats
- Name missing data, selection bias, small samples and changing definitions.
- Say what would change the conclusion.

## Deliver
- Answer first, then evidence, then caveats, then the recommended next step.
- If the user asks for a document or chart artifact, produce it; otherwise keep it inline.
